# Seguridad

No incluyas secretos, fotos personales ni pruebas de explotación con datos reales en issues públicos.

Usá la pestaña Security → Report a vulnerability del repositorio para un reporte privado. Si no está disponible, pedí un canal privado al mantenedor sin divulgar el detalle técnico. Esta app es single-owner, no multi-tenant; revisá `docs/deployment.md` antes de alojarla.
